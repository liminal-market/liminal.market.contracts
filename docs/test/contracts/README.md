# Documentation

This documentation provides an in-depth overview of the content of the folder. The folder is responsible for containing test files for various smart contracts in the system. Each test file is written using different testing frameworks and libraries, such as Chai, Hardhat, Waffle, and Smock.

### aUsdTests.ts

This is a test file for the `aUSD` contract. The tests are written using the Chai testing framework, Hardhat, and smock library. The file contains tests for various functionalities of the `aUSD` contract, such as setting the LiminalMarket address, granting and revoking roles for balance, and transferring tokens.
