# Documentation: Deployment Test Scripts

This folder contains test scripts for the deployment of various smart contracts using the Hardhat framework. The test files are responsible for testing the deployment and upgrade of contracts such as KYC, aUSD, LiminalMarket, MarketCalendar, LM, and ServiceContract, as well as managing and validating roles in a DeFi project.

## Table of Contents

- [DeploymentTest.ts](#deploymenttestts)
- [RolesTest.ts](#rolestestts)

## DeploymentTest.ts

This is a test file for the deployment of various smart contracts using the Hardhat framework. The file imports necessary libraries and modules, and tests the deployment and upgrade of contracts such as KYC, aUSD, LiminalMarket, MarketCalendar, LM, and ServiceContract.

[Read more about DeploymentTest.ts](DeploymentTest.ts)

## RolesTest.ts

This is a test file for the `Roles` class, which is responsible for managing and validating roles in a DeFi project. The test suite uses the Chai testing library, Hardhat, and Smock to create a testing environment for the smart contracts involved.

[Read more about RolesTest.ts](RolesTest.ts)
