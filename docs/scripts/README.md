### FileHelper.ts

This is a TypeScript code file that provides a utility class `FileHelper` to handle file operations related to contract addresses and ABI files. The class uses the `fs` and `Handlebars` libraries to read and write files, and manipulate templates.

[FileHelper.ts Documentation](FileHelper.ts)

### TaskHelper.ts

This file contains a TypeScript class named `TaskHelper` that provides utility methods for interacting with various smart contracts in a Hardhat environment. The class is designed to be used with the Hardhat Runtime Environment (HRE) and includes methods for funding aUSD tokens, setting market calendar as open, executing trades, creating tokens, and creating service contracts.

[TaskHelper.ts Documentation](TaskHelper.ts)

### addresses

This folder contains various TypeScript files that define classes and interfaces for managing contract addresses on different blockchain networks. The files are organized into sections, each with a brief description and a link to its own documentation.

[addresses Documentation](addresses)

### deployment

This folder is responsible for managing the deployment and upgrading of smart contracts on the Ethereum blockchain using the Hardhat framework and Ethers.js library. The folder contains TypeScript code files that define various classes and functionalities related to deployment, release, roles, and verification of smart contracts.

[deployment Documentation](deployment)

This documentation provides an in-depth overview of the content of the folder. The folder is responsible for storing template files that are used to generate various classes and configurations related to smart contracts on the Ethereum blockchain.
