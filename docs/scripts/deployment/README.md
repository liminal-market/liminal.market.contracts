# In-Depth Documentation: Deployment Folder

This folder is responsible for managing the deployment and upgrading of smart contracts on the Ethereum blockchain using the Hardhat framework and Ethers.js library. The folder contains TypeScript code files that define various classes and functionalities related to deployment, release, roles, and verification of smart contracts.

This is a TypeScript code file that contains the `Deployment` class. The class is responsible for deploying and upgrading smart contracts on the Ethereum blockchain using the Hardhat framework and Ethers.js library.

This document provides an in-depth description of the `Release.ts` file, which is a TypeScript code file. The file contains a class named `Release` that is responsible for deploying or upgrading contracts and managing their addresses and roles.

## Roles.ts

Roles.ts is a TypeScript code file that defines a `Roles` class. This class is responsible for managing roles and permissions for various contracts in a DeFi application. The class interacts with multiple smart contracts, such as LiminalMarket, AUSD, KYC, MarketCalendar, LM, and ServiceContract.

[Read more about Roles.ts](Roles.ts)
