# Liminal.market.contracts

## Description

These are the smart contracts for Liminal.market. The execution of these contracts represents a trading order going through the system, buying and selling stocks & ETFs at the broker. aUSD represents the dollar value at the broker. SecurityToken represent each stock traded in the system.

## Getting Started

1. Install the npm package:

```bash
npm install
```

2. Run the project with npx:

```bash
npx hardhat node
```

## Configuration

Configuration is optional and will be generated on the first run.
